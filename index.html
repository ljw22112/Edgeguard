EdgeGuardStops forklift accidents before they happen지게차 사고를 일어나기 전에 막습니다

Worker tags and forklift modules publish their motion to oneM2M CSEs. A MEC application on each zone's edge host predicts collisions 1–3 seconds ahead and tells the worker WAIT, then GO, while the forklift slows only as much as needed. When the forklift drives into the next zone, its oneM2M presence moves with it.

작업자 태그와 지게차 모듈이 움직임을 oneM2M CSE에 올립니다. 구역마다 엣지 호스트의 MEC 앱이 1~3초 앞의 충돌을 예측해 작업자에게 WAIT, 이어서 GO를 알리고, 지게차는 필요한 만큼만 감속합니다. 지게차가 다음 구역으로 가면 oneM2M 상의 존재도 함께 옮겨 갑니다.

From a tag to a warning, through oneM2M태그에서 경고까지, oneM2M을 거쳐

No component talks to another directly. Every hop is a oneM2M request or notification, so any other application can subscribe to the same data with access control already in place.

구성 요소끼리 직접 통신하지 않습니다. 모든 단계가 oneM2M 요청이나 알림이라, 다른 앱도 접근 제어가 갖춰진 상태로 같은 데이터를 구독할 수 있습니다.

Deployment · ESTIMED option C배포 · ESTIMED 옵션 C

One MEC host per zone, an IN-CSE above구역마다 MEC 호스트, 그 위에 IN-CSE

Each zone's MEC host runs the zone MN-CSE, the EdgeGuard MEC app and the MEC interworking proxy together (TR-0077 clause 7, option C). The IN-CSE keeps global context: home records, announcements, the federated-learning coordinator, the orchestrator and the AI agent.

구역의 MEC 호스트마다 구역 MN-CSE, EdgeGuard MEC 앱, MEC 연동 프록시를 함께 둡니다(TR-0077 7절, 옵션 C). IN-CSE는 전역 컨텍스트를 맡습니다: 홈 레코드, 공지, 연합학습 코디네이터, 오케스트레이터, AI 에이전트.

Reproduce재현

Run it on your machine직접 실행해 보기

Python 3.11, no hardware needed. The scripts start ACME CSEs locally and print PASS / FAIL for each check.

Python 3.11이면 되고 하드웨어는 필요 없습니다. 스크립트가 ACME CSE를 로컬에 띄우고 검사마다 PASS / FAIL을 출력합니다.

# clone and install
git clone https://github.com/ljw22112/Edgeguard && cd Edgeguard
pip install -r requirements.txt
# IN-CSE and two zone MN-CSEs (ACME)
scripts/acme.sh start in mn-a mn-b
# CSE handover driven by ETSI MEC zone events and RNIS
python tools/mobility_demo.py
# Mp1 service registry, AMS-triggered handover, geofence / distance
python tools/mec_platform_demo.py
# federated learning with clients deployed by the orchestrator
python tools/fl_deploy_demo.py
