# 사용자 검증 (작업자 신호 · 현장 의견)

[← README](../README.md)

시뮬레이션의 가장 큰 가정은 **사람이 신호에 어떻게 반응하는가**입니다(진동 후 0.8초 안에 멈춤, GO까지 기다림, STEP ASIDE에 비켜섬).
이 키트로 실제 사람에게 측정하고, 그 값을 시뮬레이션에 다시 넣습니다. 지게차는 쓰지 않으므로 강의실 복도에서도 안전하게 할 수 있습니다.

![휴대폰 태그 화면: WAIT · STEP ASIDE · GO](img/tag_cues.png)

## 1. 신호 반응 실험 (참가자 10명 이상, 1인 약 8분)

**가설**

| | 가설 | 판정 기준 |
|---|---|---|
| H1 | WAIT/GO가 진동 한 번(BUZZ)보다 "지게차가 지나가기 전에 다시 걷는" 비율이 낮다 | 조건별 조기 출발률 비교 |
| H2 | 신호의 뜻을 설명 없이도 이해한다 | 설문 이해도 문항 정답률 80 % 이상 |
| H3 | STEP ASIDE에 맞게 비켜선다 | 비켜섬 정확도 80 % 이상 |

**준비**: 노트북 1대(관찰자), 참가자용 휴대폰(안드로이드 크롬 권장, 아이폰은 진동 대신 소리 · 화면), 10 m 정도의 복도, 같은 Wi-Fi.

```bash
python tools/user_study.py            # 관찰자: http://<노트북 IP>:9300/observer
                                      # 참가자 휴대폰: http://<노트북 IP>:9300/tag  ("시작" 버튼으로 진동 허용)
                                      # 설문:      http://<노트북 IP>:9300/survey
```

**진행**

1. 동의를 받고(익명 번호 `P01`, `P02`… 만 기록) 참가자에게 이렇게만 안내합니다: "휴대폰을 들고 복도를 천천히 오가세요. 화면과 진동이 바뀌면 그에 맞게 행동하세요."
2. 관찰자 화면에서 번호를 넣고 **세션 시작** — 조건 순서(BUZZ ↔ WAITGO)는 번호에 따라 자동으로 바뀝니다(순서 효과 상쇄).
3. 참가자가 걷는 동안 **다음 시행**을 누르면 2~6초 뒤 무작위로 신호가 갑니다. 조건마다 5회
   (BUZZ: 진동 한 번 / WAITGO: WAIT 3회 + STEP ASIDE 2회, GO는 신호 4초 뒤 자동).
4. 관찰자는 참가자의 실제 행동을 그때그때 누릅니다: **멈춤 · 다시 걸음 · 옆으로 비켜섬**.
5. 끝나면 참가자가 휴대폰으로 **설문**(신호 이해 3문항 + 5점 척도 5문항 + 자유 의견)을 냅니다.

**분석**

```bash
python tools/study_report.py          # 조건별 멈춤 반응시간 · 조기 출발률 · GO 반응 · 비켜섬 정확도 · 이해도 · 척도 평균
                                      # → results/user_study_summary.json
python -m sim.failsafe_eval --modes coop --ux hold --comply <측정한 WAIT 준수율>   # 실측 준수율로 재평가
```

조기 출발 = WAIT · STEP ASIDE에서 GO 전에 걷기 시작 / BUZZ에서 신호 후 4초(가상의 지게차가 지나가는 시간) 안에 다시 걷기 시작.
측정한 WAIT 준수율(1 − 조기 출발률)이 시뮬레이션의 `Mover.COMPLY`입니다. 지금 결과는 준수율 50~100 % 민감도로 제시되어 있으므로
실측값이 그 범위 어디에 있는지가 곧 기대 효과입니다(85 % → 충돌 12 / 1,207, 50 % → 42 / 1,207, v1.0은 145).

## 2. 현장 의견 (안전관리자 · 물류센터 작업자 인터뷰, 3명 이상, 20분)

| # | 질문 |
|---|---|
| 1 | 지게차와 보행자 사이 사고 · 아차사고는 주로 어떤 상황에서 납니까? (교차로, 통로, 후진, 사각) |
| 2 | 지금 쓰는 안전장치(경광등, 근접 경보, 블루라이트 등)의 불편한 점은? 경보가 너무 자주 울려 꺼 두거나 무시한 적이 있습니까? |
| 3 | "기다려(WAIT) → 지나가(GO)" 신호와 진동 한 번 중 무엇을 따르기 쉽겠습니까? 이유는? |
| 4 | "옆으로 비켜서기" 신호가 현장 동선에서 가능합니까? 어떤 곳에서는 불가능합니까? |
| 5 | 지게차가 자동으로 감속되는 것에 대해 운전자 입장에서 거부감이 있습니까? 어느 정도 감속까지 받아들일 수 있습니까? |
| 6 | 태그를 늘 차고 다니게 하려면 무엇이 필요합니까? (무게, 충전, 착용 위치) |
| 7 | 아차사고 히트맵 · 개선안 리포트를 어떻게 쓰겠습니까? (교육, 동선 변경, 보고) |
| 8 | 도입 결정에 가장 중요한 것은? (비용, 설치 기간, 생산성, 법적 대응) 1인당 / 지게차당 월 비용으로 얼마까지 가능합니까? |
| 9 | 망 장애 · 서버 고장 시 어떻게 동작해야 안심이 됩니까? |
| 10 | 시범 운영에 참여할 의향이 있습니까? 조건은? |

답변은 `results/field_interviews.md`에 사람별로(익명) 정리하고, [비용 · 사업 모델](business.md)의 가정(월 구독료, 조우 수)을 실제 답으로 바꿉니다.
