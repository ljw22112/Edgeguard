# 대회 채점표 자체 평가

[← README](../README.md)

대회 운영 측이 제시한 평가 항목에 맞춰, 업데이트할 때마다 이 표를 갱신합니다.
배점이 공개되지 않아 항목마다 20점(총 100점)으로 가정한 **자체 추정**입니다.
