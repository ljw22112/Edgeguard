# Final video: storyboard and narration

[← README](../README.md)

On YouTube: https://youtu.be/P2JI5ZG6PIg. `results/edgeguard_final.mp4` lasts 3 min 31 s, at 1920×1080, with **spoken English narration** (Piper TTS, generated by the build) and captions (`results/edgeguard_final.srt`). Each card lasts at least as long as its narration. Rebuild with `python tools/mobility_map.py && EG_VOICE=<path>/en_US-lessac-high.onnx python tools/make_final_video.py` (`pip install piper-tts`; voice from rhasspy/piper-voices). The cards and the timeline are in `tools/make_final_video.py`.

To record a human voice instead, read the narration over the silent build (`EG_VOICE` unset) and mux it:

```bash
ffmpeg -i results/edgeguard_final.mp4 -i narration.m4a -c:v copy -c:a aac -shortest results/edgeguard_final_voice.mp4
```
